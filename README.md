# SaveTinker Zelda editors

Editors for [SaveTinker](https://github.com/mrissaoussama/SaveTinker).

| Editor | Game |
|---|---|
| `oot-switch2` | The Legend of Zelda: Ocarina of Time (Switch 2) |

Player, items, songs, dungeons, story, chests, Gold Skulltulas, spawn point and every named flag (`data/flags.json`),
plus dialogue and actor data read from the game.

Repository URL:

```
https://raw.githubusercontent.com/mrissaoussama/savetinker-zelda/main/repo/repo.json
```

Update with `savetinker-cli pack editors repo`.
